# 里程碑计划

## 1. 目标

将项目拆为若干阶段，控制范围、降低风险、确保核心闭环先可用。

## 2. 阶段划分

### M0：方案冻结
目标：文档、字段、状态机、权限、同步策略冻结。
交付：
- PRD
- 字段字典
- 状态机
- 权限矩阵
- 同步规则

### M1：基础底座
目标：搭起中心主档、飞书登录、任务 CRUD。
交付：
- PostgreSQL schema
- API 基础框架
- Web 基础页面
- 飞书登录接入

### M2：多维表格打通
目标：实现 task_master 基本双向同步。
交付：
- 多维表格字段映射
- 写回幂等
- 基本对账

### M3：飞书任务与卡片打通
目标：实现任务中心同步和周提醒闭环。
交付：
- 飞书任务映射
- 周一提醒
- 临期提醒
- 卡片交互回写

### M4：月结与驾驶舱
目标：月初统计与老板视图上线。
交付：
- 月结快照
- 继承逻辑
- 老板驾驶舱
- leader 视图

### M5：日历与补偿完善
目标：关键事项日历同步和冲突修复完善。
交付：
- 日历映射
- 对账修复台
- 冲突处理台

## 3. MVP 建议范围

MVP 截止到 M4：
- 不要求一开始覆盖所有复杂边界
- 先保证任务、提醒、月结、驾驶舱闭环
- 日历可先只覆盖关键事项
