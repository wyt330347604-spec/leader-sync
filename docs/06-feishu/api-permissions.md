# 飞书能力与权限清单

## 1. 目标

明确本项目的飞书自建应用需要启用哪些能力、申请哪些权限、为什么需要这些权限。

## 2. 应用能力

本项目建议启用以下能力：

- 网页应用
- 机器人
- 飞书卡片
- 多维表格 API
- 飞书任务 API
- 飞书日历 API
- 登录与用户身份识别
- 事件订阅
- 可选：多维表格插件 / 小组件

## 3. 能力用途说明

### 3.1 网页应用
用于：
- 工作台首页
- 我的任务页
- leader 视图
- 老板驾驶舱
- 冲突处理后台

### 3.2 机器人 + 卡片
用于：
- 周一提醒
- 临期提醒
- 月报推送
- 异常告警
- 卡片内轻交互

### 3.3 多维表格 API
用于：
- 读取任务台账
- 写回任务台账
- 构建管理视图
- 与中心主档双向同步

### 3.4 飞书任务 API
用于：
- 创建任务
- 更新任务
- 标记完成
- 同步任务链接与状态

### 3.5 飞书日历 API
用于：
- 创建关键任务日程
- 更新日程时间
- 对接时间承诺与提醒

### 3.6 用户身份
用于：
- 登录后识别当前用户
- 识别负责人、leader、老板
- 执行权限控制

## 4. 权限申请分类

### 4.1 基础身份类
- 获取用户基本信息
- 获取组织架构信息（如部门、直属上级）
- 获取用户标识

### 4.2 多维表格类
- 读取多维表格元数据
- 读取记录
- 新增记录
- 更新记录
- 读取视图（如需要）

### 4.3 任务类
- 创建任务
- 查询任务
- 更新任务
- 删除/归档任务（如业务需要）

### 4.4 日历类
- 创建日程
- 读取日程
- 更新日程
- 监听日历相关事件（在用户授权前提下）

### 4.5 消息与卡片类
- 发送消息
- 发送卡片
- 接收卡片交互回调

### 4.6 事件订阅类
- 多维表格记录变更事件
- 卡片回调事件
- 可选：日历事件变更

## 5. 权限申请原则

1. 只申请真正需要的权限
2. 权限变更必须更新本文件
3. 权限变更必须走发布流程
4. 高风险权限要在内部说明用途和边界

## 6. 建议的接入顺序

### Phase 1
- 身份识别
- 多维表格读写
- 消息与卡片
- 网页应用

### Phase 2
- 飞书任务能力
- 任务侧双向同步（API + 对账补偿模式）

### Phase 3
- 日历能力
- 日历侧双向同步

## 7. 注意事项

- 权限新增后通常需要重新发布
- 企业管理员审批可能影响上线节奏
- 日历事件能力要单独关注用户授权范围
