# 飞书任务与日历映射规则

> 字段名以 field-dictionary.md 为准。

## 1. 目标

定义中心主档与飞书任务、飞书日历之间的映射规则，作为双向同步实现依据。

## 2. 任务映射

| 中心字段 | 飞书任务字段 | 方向 | 说明 |
|---|---|---|---|
| task_uid | 自定义字段 / 描述中隐藏标识 | 系统 -> 任务 | 用于回写映射 |
| title | title | 双向 | 主标题 |
| detail | description | 双向 | 详情 |
| due_at | due_time | 双向 | 截止时间 |
| status | complete / status | 双向 | 需统一内部枚举 |
| progress_percent | 自定义字段 | 双向 | 若任务侧无法承载则只单向展示 |
| assignee_user_id | executor | 系统 -> 任务 | 负责人仅从中心主档单向同步到飞书任务，不从任务侧回写 |
| boss_attention_flag | 自定义标签 | 系统 -> 任务 | 展示为重点 |

### 任务侧双向策略说明

当前飞书任务侧双向同步采用"API 写入 + 周期性对账补偿"模式（见 event-subscriptions.md 3.4），不依赖飞书任务原生回调事件。任务侧的状态和进展变更通过定时对账拉取，而非实时回调驱动。

## 3. 日历映射

| 中心字段 | 飞书日历字段 | 方向 | 说明 |
|---|---|---|---|
| task_uid | description 扩展信息 | 系统 -> 日历 | 回写定位 |
| title | summary | 双向 | 标题 |
| due_at / start_at | start_time / end_time | 双向 | 节点或日程时间 |
| assignee_user_id | attendees | 系统 -> 日历 | 参与人（单向，不从日历回写负责人） |
| detail | description | 双向 | 详情 |

## 4. 同步策略

### 飞书任务
- 默认同步所有"可执行任务"
- 若任务被取消或关闭，任务中心同步关闭状态
- 任务中心侧进展与完成可回写中心主档（通过对账补偿）

### 飞书日历
- 仅同步符合条件的关键任务
- 条件示例：有明确时间点 / 属于关键里程碑 / 老板关注 / 需要提醒
- 日历更适合表达时间承诺，不适合承载所有任务
- 已绑定日历事件的任务，日历侧可回写 start_at / due_at

## 5. 冲突优先级

- 组织与指派关系：中心主档优先
- 时间字段：若来源为日历编辑且任务已绑定日历事件且字段属于时间域，优先采纳日历
- 状态与进展：按字段主权和版本判定
- 负责人：中心主档优先，飞书任务和日历侧均不回写负责人

## 6. 异常情况

- 找不到映射关系：进入异常队列
- 任务或日历被手工删除：标记为 orphaned，并发起修复
- 重复创建外部对象：以 task_uid 去重
