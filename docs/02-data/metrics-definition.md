# 指标口径定义

## 1. 目标

定义驾驶舱、月报和团队看板中使用的核心统计指标，避免各页面口径不一致。

> **口径变更记录（2026-06 起生效）**：完成率/延期率改为**累计口径**——分母由「本月内到期」改为「截至本月末应完成全集」，使两率值域回到 [0,1] 且互补。背景见 `docs/superpowers/specs/2026-06-01-monthly-close-overflow-fix.md`。月结前已冻结的快照不追溯重算。

## 2. 指标列表

### 2.1 本月新增任务数
统计口径：`month_bucket = 当前月份` 且创建时间在本月的任务数。

### 2.2 完成任务数（累计）
统计口径：`due_at ≤ 本月末` 且 `status = done` 的任务数（即「截至本月末应完成、且已完成」）。

### 2.3 应完成任务数（累计，分母）
统计口径：`due_at ≤ 本月末`、状态不为 `shelved`、未删除的任务数（含已完成）。即「截至本月末应当完成的全集」，作为完成率/延期率的统一分母 `month_due_count`。

### 2.4 完成率
公式：`完成任务数(累计) / 应完成任务数(累计)`（即 `month_done_count / month_due_count`），值域 [0,1]。

### 2.5 延期任务数（累计）
统计口径：`due_at ≤ 本月末` 且 `status ∉ {done, shelved, closed}` 的任务数（截至本月末到期、仍未完成）。

### 2.6 延期率
公式：`延期任务数(累计) / 应完成任务数(累计)`（即 `month_overdue_count / month_due_count`），值域 [0,1]。

### 2.7 继承任务数
统计口径：`is_carried_over = true` 且 `month_bucket = 当前月份`。

### 2.8 老板关注任务数
统计口径：`boss_attention_flag = true`。

## 3. 统计注意事项

- 月报以 monthly_snapshot 为准
- 实时页面可用 task 实时统计
- 月结后不得再改上月快照口径
- 完成率和延期率的分母统一为 `month_due_count`（累计应完成全集）
- 完成率 + 延期率 ≈ 1（差额来自 `closed` 等终态）；二者均 ∈ [0,1]
- 写库前 `month_*_rate` 经 `clampRate` 钳到 ≤ 9.9999，兜底 `numeric(5,4)` 列防溢出
