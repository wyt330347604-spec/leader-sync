# 产品需求文档（PRD）

## 1. 文档信息

- 产品名称：飞书领导月度督办系统
- 当前版本：v0.2
- 文档状态：Draft
- 面向对象：老板、业务负责人、产品、研发、运维

## 2. 背景与问题定义

当前月度事项依赖多维表格分月管理，但存在：

- 跨月继承不清晰
- 个人、leader、老板视角混杂
- 提醒依赖人工
- 缺乏任务、日历、待办一体化
- 月初完成情况和继承情况统计成本高
- 指派关系不透明，难以区分老板指派、上级指派、平级协同

## 3. 产品目标

### 3.1 业务目标

- 建立统一任务主档
- 形成员工 / leader / 老板三级视角
- 将"看板 + 提醒 + 月结 + 复盘"固化为系统动作
- 统一任务发起、指派、执行、完成、延期、继承口径

### 3.2 技术目标

- 用飞书企业自建应用承载所有能力
- 以服务端 + 数据库作为中心同步中枢
- 以多维表格为业务操作台与管理台账
- 以飞书任务、日历、卡片作为执行触达层
- 保证双向同步可追踪、可修复、可扩展

## 4. 用户角色

### 4.1 员工
- 查看自己的任务
- 更新进展
- 标记完成
- 申请延期
- 查看本周应完成和临期事项

### 4.2 Leader
- 查看团队本月事项
- 指派团队内任务
- 验收 / 退回任务
- 查看团队完成率、延期率、继承量

### 4.3 老板
- 查看全局本月事项
- 按 leader 查看任务分布
- 发起重点任务
- 查看月初复盘与风险项

### 4.4 PMO / 运营
- 维护任务口径
- 维护月结
- 处理同步冲突
- 配置提醒策略

## 5. 核心场景

1. 老板创建重点任务并指派给某 leader
2. leader 将任务拆解并指派给团队成员
3. 员工在飞书任务或系统页面更新进展
4. 系统每周一推送本周应完成任务
5. 系统推送临近延期任务提醒
6. 月初自动生成上月完成情况与继承情况
7. 老板查看各 leader 的本月任务与风险项
8. 多维表格、任务、日历之间保持双向同步

## 6. 非目标

- 不替代项目管理全栈系统
- 不处理复杂审批流程
- 不作为组织通讯录系统
- 不作为通用文档平台

## 7. 业务对象

- 任务（Task）
- 任务进展日志（Task Progress Log）
- 月结快照（Monthly Snapshot）
- 同步日志（Sync Log）
- 用户与角色（User / Role）
- 外部映射（External Mapping）

## 8. 功能需求

### 8.1 任务创建

#### 描述
系统支持老板、leader、员工按权限创建任务。

#### 规则
- 用户提交必填字段（A 类）：标题、负责人、任务类型、预计完成时间（due_at）、优先级
- 系统自动填充（B 类）：发起人、指派人、创建时间、归属月份、归属 leader、状态、版本号
- 支持标记老板关注
- 支持设置协作者

#### 验收标准
- 创建后自动生成任务唯一 ID
- 创建后写入中心主档
- 根据规则同步到多维表格与飞书任务
- 如符合条件，可同步到飞书日历

### 8.2 任务指派

#### 描述
支持老板、leader、成员之间指派，但必须保留指派关系语义。

#### 规则
- 保留发起人、指派人、负责人
- 指派关系类型必须明确
- 变更负责人必须写入日志
- 可配置是否允许成员跨人指派

#### 验收标准
- 能区分老板指派 / 上级指派 / 平级协同 / 自领 / 系统继承
- 任务历史可追踪

### 8.3 任务执行与进展更新

#### 描述
支持多入口更新任务状态与进展。

#### 入口
- 多维表格
- 网页应用
- 飞书任务
- 飞书卡片交互

#### 可更新字段
- 状态
- 进度百分比
- 最新进展
- 阻塞原因
- 延期原因
- 实际完成时间

#### 验收标准
- 任一入口更新后，系统中心主档刷新
- 同步到其他入口
- 不产生循环回写

### 8.4 我的任务

#### 描述
员工进入系统默认看到自己的任务。

#### 页面模块
- 我的本周应完成
- 我的临近延期
- 我的已延期
- 我的老板关注任务
- 我发起的
- 我协同的

#### 验收标准
- 默认筛选为当前登录用户
- 支持按状态 / 截止日期 / 发起关系过滤

### 8.5 Leader 视图

#### 页面模块
- 团队本月任务
- 团队本周到期
- 团队临近延期
- 团队已延期
- 团队新增 / 完成 / 继承

#### 验收标准
- 可按成员查看
- 可按任务类型和优先级过滤
- 展示团队月度统计卡片

### 8.6 老板驾驶舱

#### 页面模块
- 按 leader 汇总的本月事项
- 重点任务
- 高风险任务
- 已延期任务
- 上月完成率
- 本月继承量
- 指派关系分布

#### 验收标准
- 支持按月份、leader、部门过滤
- 支持跳转到明细任务列表
- 所有统计基于中心主档与月快照

### 8.7 周提醒

#### 描述
每周一自动推送任务提醒。

#### 推送对象
- 员工：个人本周应完成 + 临近延期
- leader：团队本周应完成 + 临近延期
- 老板：全局重点 + 风险

#### 验收标准
- 支持定时自动推送
- 支持卡片点击后跳转任务详情
- 支持提醒发送日志

### 8.8 月结与月报

#### 描述
每月初生成上月任务完成与继承结果。

#### 输出
- 个人月报
- leader 月报
- 老板月报
- 月快照数据
- 下月继承任务

#### 验收标准
- 月报口径可重复计算
- 月结完成后锁定上月统计口径
- 未完成任务根据规则继承（新建记录）

### 8.9 双向同步

#### 描述
系统支持中心主档与多维表格、飞书任务、飞书日历之间双向同步。

#### 要求
- 字段级主权
- 幂等处理
- 冲突检测
- 对账补偿
- 可审计

#### 验收标准
- 支持 source_event_id
- 支持 version
- 支持 sync_log
- 支持失败重试与人工冲突处理

## 9. 统计口径

核心统计包括（详见 metrics-definition.md）：

- 本月新增任务数
- 本月应完成任务数
- 本月完成任务数
- 本月延期任务数
- 本月继承任务数
- 完成率（= 完成数 / 应完成数）
- 延期率（= 延期数 / 应完成数）
- 按 leader 分布
- 按任务类型分布
- 按指派关系分布

## 10. 核心页面建议

- 工作台首页
- 我的任务页
- 团队任务页
- 老板驾驶舱
- 任务详情页
- 冲突处理页
- 月结结果页

## 11. 风险与异常处理

- 同步失败：进入重试队列
- 同步冲突：标记冲突并进入人工处理
- 事件重复：按 event_id 幂等
- 外部系统不可用：记录失败日志并补偿
- 月结失败：允许重跑
