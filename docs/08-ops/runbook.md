# 运维 Runbook

## 1. 常规巡检

每日检查：
- 应用存活
- 回调成功率
- 同步失败率
- 重试队列积压
- 数据库磁盘使用率
- 证书剩余有效期

## 2. 常见故障处理

### 2.1 飞书回调失败
- 检查域名与 HTTPS
- 检查验签配置
- 检查回调接口日志
- 检查飞书开放平台事件订阅状态

### 2.2 同步大量失败
- 检查 token 是否过期
- 检查飞书 API 限流
- 检查 Redis 锁是否卡住
- 暂停补偿队列，避免扩大写入

### 2.3 月结失败
- 执行 dry-run
- 检查快照写入权限
- 检查是否有脏数据
- 若需重跑，先确认是否幂等

## 3. 人工修复工具

建议提供：
- 任务重试同步
- 重新生成外部映射
- 手工标记冲突已解决
- 月结 dry-run 与 execute
