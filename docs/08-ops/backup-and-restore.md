# 备份与恢复

## 1. 目标

确保系统在误删、回调异常、部署错误、服务器损坏时可恢复。

## 2. 备份范围

- PostgreSQL 全量备份
- PostgreSQL Binlog / WAL（若启用）
- 应用配置文件
- 关键环境变量清单
- Nginx/Caddy 配置
- 证书文件

## 3. 备份策略

### 数据库
- 每日全量备份
- 保留 7 日短期备份
- 保留 4 周周备份
- 每月保留 1 份长期备份

### 配置文件
- 代码仓库纳入版本控制
- 敏感配置使用密码管理器或安全存储

## 4. 恢复流程

1. 确认恢复时间点
2. 选择对应备份包
3. 恢复数据库到临时实例
4. 校验关键表数量与最新记录
5. 切换应用指向恢复实例
6. 对账外部系统映射关系

## 5. 演练要求

- 每季度至少一次恢复演练
- 记录恢复耗时
- 记录恢复后的校验步骤
